## Step 2 — Render API (~5–10 min)

Render service: **`bog-accounting-api`**

1. Dashboard → **bog-accounting-api** → confirm auto-deploy from `main` (or **Manual Deploy** → Deploy latest).
2. Wait until **Live** (build runs `prisma db push` — no manual migration).
3. Verify:

```bash
curl -s https://bog-accounting-api.onrender.com/api/health
curl -s https://bog-accounting-api.onrender.com/api/setup/owner-status
```

Expect health: `"database": true`, `"schemaReady": true`  
Expect owner-status: `"ownerSetupCompleted": true`, `"presidentEmail": "<your email>"`

**Env check (Render → Environment):**

| Variable | Required |
|----------|----------|
| `DATABASE_URL` | Supabase URI |
| `JWT_SECRET` | set |
| `FRONTEND_URL` | `https://bog-accounting-v5.vercel.app` |
| `OPENAI_API_KEY` | optional (AI CPA) |
| `BOG_BOOTSTRAP_USERS` | **unset** on production |
